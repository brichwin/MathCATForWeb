Braille Math Input for the Canvas RCE

Type math in UEB or Nemeth braille, check it with a live preview and speech, and insert it into the Canvas Rich Content Editor as MathML. You can also put the cursor next to existing math to load it back into braille and edit it.

Install the bookmarklet

Braille Math Input

With a mouse

  1. Show your browser's bookmarks bar.
  2. Drag the Braille Math Input link to the bookmarks bar.

With the keyboard or a screen reader

Dragging isn't practical without a mouse, so create the bookmark by hand instead:

  1. Select Copy bookmarklet code below.
  2. Bookmark any page (Ctrl+D, or Cmd+D on a Mac). Name it Braille Math Input and save it in the bookmarks bar.
  3. Open the browser's bookmark manager (Ctrl+Shift+O in Chrome and Edge), find the new bookmark, choose Edit, and paste the copied code into the URL field in place of the page address.

The code is also printed under Manual bookmark code.

Running it

  1. Open a Canvas page, assignment, discussion or quiz in edit mode, and place the cursor in the Rich Content Editor where the math should go.
  2. Run the bookmarklet:
    • Mouse: select Braille Math Input on the bookmarks bar.
    • Keyboard, Chrome and Edge: press Alt+Shift+B to move to the bookmarks bar, use the arrow keys to reach Braille Math Input, and press Enter.
    • Keyboard, Safari: open the Bookmarks menu from the menu bar and choose Braille Math Input.
  3. The Braille math input dialog opens with the cursor in the braille box.

Then use the shortcut. Once the bookmarklet has run on a page, Alt+Shift+M (Option+Shift+M on a Mac) reopens the dialog from the editor without going back to the bookmarks bar. It keeps working, including in editors that appear later such as discussion replies, until you reload the page or Canvas loads a new one. Then run the bookmarklet once more.

How to use it

Add new math

  1. Choose the braille code: UEB or Nemeth.
  2. Type the math in the Math in braille box. You can chord with six keys, type ASCII braille, or enter Unicode braille (see Three ways to type braille).
  3. Check the result. As you type, the dialog shows the input as braille cells, a rendered preview, the spoken form, and the MathML (under MathML).
  4. Turn on Display math (block) if the math should sit on its own line.
  5. Press Enter or select Insert. The math goes in at the cursor and focus returns to the editor.

Edit existing math

  1. In the editor, put the cursor inside the math, select it, or place the cursor directly after it.
  2. Run the bookmarklet or press the shortcut. The dialog says Editing the math next to the cursor and loads the math as braille in the chosen code.
  3. Make your changes and press Enter or select Replace. The old math is replaced and the cursor goes right after the new math.

Older Canvas equation images (made with the Canvas equation editor) can be edited the same way. The tool reads the image's LaTeX, and Replace swaps the image for MathML.

Cancel or undo

Press Escape or select Cancel to close the dialog without changing anything. After inserting or replacing, a single Undo in the editor (Ctrl+Z, or Cmd+Z on a Mac) reverses the change.

Three ways to type braille

Six-key entry

With Six-key entry checked, the keyboard works like a Perkins brailler. Press the keys for a cell together and release them; the cell is entered when all keys are up.

Left hand
Sdot 3
Ddot 2
Fdot 1
Right hand
Jdot 4
Kdot 5
Ldot 6

Space by itself enters a blank cell, and Backspace deletes a cell. The keys go by position on the keyboard, so the layout is the same on any keyboard language. While six-key entry is on, other letter keys don't type.

ASCII braille

Uncheck Six-key entry and type North American ASCII braille. For example, ?1/2# in Nemeth is one half. The As braille line shows the cells your typing became.

Unicode braille and braille displays

Unicode braille characters (such as ⠹⠂⠌⠆⠼) can be typed or pasted in either mode. Text that a screen reader sends from a braille display's keyboard gets through even when six-key entry is on.

Examples

Example input in each braille code, with the speech the tool produces
Math Code Braille ASCII braille Speech
12 Nemeth ⠹⠂⠌⠆⠼ ?1/2# 1 half
x2+1 Nemeth ⠭⠘⠆⠐⠬⠂ X^2"+1 x squared plus 1
x2+1 UEB ⠭⠰⠔⠼⠃⠐⠖⠼⠁ X;9#B"6#A x squared plus 1
b Nemeth ⠜⠃⠻ >B] the square root of b

Switching between UEB and Nemeth in the dialog converts whatever is in the box to the other code.

Limits to keep in mind

  • Only UEB and Nemeth are supported.
  • The bookmarklet has to run once on each page load before the keyboard shortcut works.
  • Math loaded for editing is re-brailled by MathCAT, so it may not match exactly how it was first typed, even though the math is the same.
  • MathCAT's braille reader is new, and a few things it brailles are read back as different math. For example, ac written next to each other in Nemeth is read back as the word ac (spoken acres after a number). When you load math to edit, the dialog checks for this and shows a Check before replacing message. If you don't change the braille, Replace keeps the original math exactly.
  • Editing a Canvas equation image replaces it with MathML; Undo brings the image back.
  • Canvas cleans up MathML when a page is saved. Check the saved page to make sure the math looks and reads as expected.
  • The braille back-translation comes from an early preview release of MathCAT (0.8.0-alpha). Please report anything that converts incorrectly.

How it works

The bookmarklet loads a WebAssembly build of MathCAT, by Neil Soiffer and the DAISY Consortium, which converts braille to MathML and MathML to speech and braille. Everything runs in your browser: your math is not sent to any server. The program files come from cdn.jsdelivr.net, and the preview loads MathJax 2.7.7 from cdnjs.cloudflare.com, the same MathJax version Canvas uses.

The source is in MathCATForWeb on GitHub.

Manual bookmark code

Use this if you are creating the bookmark by hand instead of dragging the link above.

javascript:(()=>{import('https://cdn.jsdelivr.net/gh/brichwin/MathCATForWeb@0.8.0-alpha.1-web.6/bookmarklet/braille-math.js').then(m=>m.run()).catch(e=>alert('Braille math input could not load: '+e))})()

To use a different shortcut key, change m.run() to, for example, m.run({shortcut:'Alt+Shift+K'}).
