# WebAssembly/JavaScript Interface for MathCAT

MathCAT is a library that supports conversion of MathML to speech and braille among other things.

This project is a rough stab at adding a WebAssembly/JavaScript interface to MathCAT.
Visit [the MathCAT project page](https://nsoiffer.github.io/MathCAT/) for more info or if you want to play around with MathCAT's capabilities, [try out the demo](https://nsoiffer.github.io/MathCATDemo/).

## Required rustc version

MathCAT uses rust features that require a recent rustc version:
rustc 1.92.0 (ded5c06cf 2025-12-08)

## To build this project:

- In a folder, download or git clone MathCAT
  - **The math input functions (below) need MathCAT's `braille-parser` branch** (0.8.0-alpha.x), which is not yet merged into `main`:
    ```sh
    git clone -b braille-parser https://github.com/daisy/MathCAT
    ```
    (With an existing clone: `git fetch && git checkout braille-parser && git pull`.)
- In the same folder, download or git clone MathCATForWeb
- Your folder structure should look like this:
  ```
  ParentFolder/
  ├── MathCAT/
  └── MathCATForWeb/
  ```
- Install 'wasm-pack' (if not already installed):
  ```sh
  cargo install wasm-pack
  ```
- Build the project:
  ```sh
  wasm-pack build --target web --release
  ```
  - If it builds successfully, you should get a message like: "Your wasm pkg is ready to publish at .../MathCATForWeb/pkg."

## Files in the `pkg` folder.
After the project is built using wasm-pack, the pkg folder contains several files. Here is a description of each file:
 - mathcat_web_bg.wasm: The WebAssembly binary. This is the core file that contains the compiled WebAssembly code.
 - mathcat_web.js: This JavaScript file provides the bindings to interact with the WebAssembly module. It typically includes functions to initialize the WebAssembly instance and to call its exports.
 - mathcat_web_bg.js: This is a JavaScript glue code file that handles the low-level interaction between the WebAssembly binary and JavaScript.
 - mathcat_web.d.ts: TypeScript declaration file, useful if you are using TypeScript.
 - package.json: This file is used for npm to manage dependencies and is not typically needed if you are just serving the files from a web server without using npm.
 - README.md: Documentation file generated by wasm-pack. Not needed for deployment.
### Essential Files for Web Server Deployment
For deploying your WebAssembly module to a web server, you only need a subset of the files in the `pkg` folder. 
 - mathcat_web_bg.wasm: The WebAssembly binary.
 - mathcat_web.js: The JavaScript file that initializes and interacts with the WebAssembly module.
 - mathcat_web_bg.js: The JavaScript glue code file.

## Example Deployment Structure
Here's an example deployment structure:
```
/your_deployment_directory
├── index.html
└── mathCATForWeb
    ├── mathcat_web.js
    ├── mathcat_web_bg.js
    └── mathcat_web_bg.wasm
```
### Example `index.html`
In the following example, note:
 - The path to the `mathcat_web.js` file must be correct in the import statement.
 - You must call `wasm_set_rules_dir('Rules')` before calling any of the other MathCAT functions (other than `wasm_get_version`).
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>MathCAT Web</title>
</head>
<body>
    <script type="module">
        import init, { MathCAT as mathCAT } from './mathCATForWeb/mathcat_web.js';

         async function run() {
            await init()

            console.log('MathCAT Version:', mathCAT.getVersion())

            try {
                const sampleMathML = `<math><mrow><mfrac><mi>x</mi><mi>y</mi></mfrac><mo>+</mo><mn>2</mn></mrow></math>`

                mathCAT.setRulesDir('Rules')
                console.log('Rules directory set')

                mathCAT.setPreference('SpeechStyle', 'ClearSpeak')
                mathCAT.setPreference('Verbosity', 'Verbose')

                const canonicalMathML = mathCAT.setMathML(sampleMathML)
                console.log('Canonical MathML:', canonicalMathML)

                const spokenText = mathCAT.getSpokenText()
                console.log('Spoken Text:', spokenText)

                const braille = mathCAT.getBraille('')
                console.log('Braille:', braille)

            } catch (error) {
                console.error('Error using MathCAT: ', error)
            }
        }

        run();
    </script>
  </body>
</html>
```
Which should produce something similar to the following console output:
```
[Log] MathCAT Version: – "0.6.4" (index.html, line 15)
[Log] Rules directory set (index.html, line 21)
[Log] Canonical MathML: – " <math id='Msdhne7g-0' data-id-added='true'>…" (index.html, line 27)
[Log] Spoken Text: – "x over y plus 2" (index.html, line 30)
[Log] Braille: – "⠹⠭⠌⠽⠼⠬⠆" (index.html, line 33)
```

## Math input: braille, ASCIIMath and LaTeX → MathML (MathCAT 0.8.0-alpha)

Built against MathCAT's `braille-parser` branch, `MathCAT` also has these functions:

| Function | What it does |
|---|---|
| `getBrailleInputCodes()` | Input codes the parser accepts: `UEB`, `Nemeth`, `ASCIIMath`, `LaTeX` |
| `brailleToMathML(input, code)` | Returns plain `<math>…</math>` (no MathCAT ids). Does **not** change the current expression. Use this for pasting into an editor. |
| `setMathMLFromBraille(input, code)` | Parses the input and makes it the current expression (like `setMathML`). Returns the canonical MathML with ids. Then call `getSpokenText()` / `getBraille('')`. |
| `translateBraille(input, fromCode, toCode)` | Back-translates and re-brailles, e.g. Nemeth → UEB. Restores the `BrailleCode` preference afterwards. |
| `normalizeBrailleInput(input, code)` | The input cleanup the other three apply automatically (taken from the MathCAT demo): for UEB/Nemeth, North American ASCII braille (`?A/B#`) becomes Unicode braille; for ASCIIMath/LaTeX, computer-braille cells become text; spaces between braille cells become U+2800. |
| `getSupportedBrailleCodes()`, `getSupportedLanguages()` | Codes and languages available in the bundled rules. |

```js
mathCAT.setRulesDir('Rules');
mathCAT.brailleToMathML('⠹⠁⠌⠃⠼', 'Nemeth');      // "<math><mfrac><mi>a</mi><mi>b</mi></mfrac></math>"
mathCAT.setMathMLFromBraille('?A/B#', 'Nemeth');  // ASCII braille works too
mathCAT.getSpokenText();                          // "eigh over b"
mathCAT.translateBraille('⠹⠁⠌⠃⠼', 'Nemeth', 'UEB'); // "⠰⠰⠷⠁⠨⠌⠃⠾"
```

Parse errors are thrown as strings. `input.html` is a test page for these functions. Serve the folder over HTTP (for example `python3 -m http.server`) and open `/input.html`.

A native smoke test runs the same calls without a browser: `cargo test --release -- --nocapture`.

## Braille Math Input bookmarklet (Canvas RCE / TinyMCE)

`bookmarklet/braille-math.js` adds a dialog to any page with a TinyMCE editor (including the Canvas Rich Content Editor) for entering math in **UEB** or **Nemeth** braille:

- **Three ways to type:** six-key chording (F D S J K L = dots 1–6, Space = blank cell), ASCII braille (`?1/2#`), or Unicode braille. Input from a screen reader or braille display gets through even when six-key entry is on.
- **Live output:** a preview rendered by an isolated MathJax 2.7.7 using `TeX-MML-AM_SVG` (the same build and config Canvas uses), MathCAT speech, and the MathML. If you choose, the dialog announces the dots of each chord and reads the speech after a pause.
- **Editing existing math:** if the cursor is inside or just after `<math>` or a Canvas equation image (`img.equation_image`), that math is converted to braille in the chosen code and loaded for editing, and **Replace** swaps it out. Equation images are read from their LaTeX and replaced with MathML.
- **Switching codes** translates what's in the box between UEB and Nemeth.
- **Enter** inserts or replaces, **Escape** cancels, and a single Undo in the editor reverts the change. Settings are stored in `localStorage` under `atac_iu_edu_braillemath_config`.

### Install

Make a bookmark whose URL is the line below, replacing `TAG` with a tag that contains `bookmarklet/` (for example `0.8.0-alpha.1-web.2`):

```
javascript:(()=>{import('https://cdn.jsdelivr.net/gh/brichwin/MathCATForWeb@TAG/bookmarklet/braille-math.js').then(m=>m.run()).catch(e=>alert('Braille math input could not load: '+e))})()
```

Click in the editor, then click the bookmark. The module loads `../pkg/` from the same tag, so the bookmarklet and the WebAssembly build always match.

If a site's Content Security Policy blocks scripts from `cdn.jsdelivr.net`, the bookmarklet shows the "could not load" message. The preview iframe also needs `cdnjs.cloudflare.com`, which Canvas already uses for MathJax.

### Keyboard shortcut

After the bookmarklet has run once, **Alt+Shift+M** (**Option+Shift+M** on a Mac) reopens the dialog until you leave or reload the page. The dialog's description announces the shortcut. It works:

- inside any TinyMCE editor, including editors created later (such as a discussion reply box) and editors in same-origin frames such as New Quizzes;
- anywhere else on the page, in which case it uses the editor that was last active.

The shortcut avoids keys used by Chrome and Edge (Alt+Shift+B, I, T and A), TinyMCE (Alt+Shift+digits), the Canvas RCE (Alt+F8, Alt+F9, Alt+F10, Ctrl+F9, Alt+0) and NVDA's global Ctrl+Alt+N. To use a different one, pass it to `run`:

```
javascript:(()=>{import('https://cdn.jsdelivr.net/gh/brichwin/MathCATForWeb@TAG/bookmarklet/braille-math.js').then(m=>m.run({shortcut:'Alt+Shift+K'})).catch(e=>alert('Braille math input could not load: '+e))})()
```

A bookmarklet can't run on its own when a page loads, so a reload or a full Canvas page change means running it once more. To have the shortcut on every Canvas page automatically, load the same module from a userscript manager such as Tampermonkey, using `m.install()` in place of `m.run()`.

### Testing locally

`bookmarklet/test.html` is a TinyMCE 5 page configured to keep MathML. It includes an existing fraction and a Canvas-style equation image. Serve the repo (`python3 -m http.server`) and open `/bookmarklet/test.html`. The query parameters `?tinymce=URL&mathjax=URL` point it at local copies of TinyMCE and MathJax.
